# Node.js + Express + MongoDB Project

This project is a **Node.js + Express + MongoDB** application with user authentication, OTP verification, contact form, and admin features. It also supports sending promotional emails.

---


---

## **1️⃣ Install Dependencies**

Open terminal in the **Backend folder** and run:

```bash
npm install 
express mongoose 
cors dotenv 
bcryptjs nodemailer
npm install 
-D nodemon   # optional (auto-restart server during development)

node server.js
